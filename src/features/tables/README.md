# テーブルの見た目

<!-- config/features.json から生成。説明・設定は config 側を編集してください。 -->

テーブルの配色・罫線・余白を整えます。

## 使い方

table: のテーブルに適用します。

## 構成と現在の設定

- CSS：有効
- UserScript：—

| ファイル | 役割 |
| --- | --- |
| [style.css](style.css) | 表示・装飾 |

有効・無効と読み込み順は [config/features.json](../../../config/features.json) で管理します。変更後に `npm run build` を実行してください。
